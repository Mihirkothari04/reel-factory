# Mode: Kinetic Explainer (`kinetic`)

**Identity:** faceless. Every sentence gets its own designed composition; the voice is fast and continuous; the screen never holds still longer than 3 s. The default mode and the most automatable top-tier format in the corpus (Creator 30, Creator 63, Creator 32, Creator 27).

## Construction
- **Stage:** full frame (y 200–1290); hook sticker or kinetic headline top-centre.
- **Visual sources:** rebuilt UI (`repo`, `terminal`, `code`, `chat`), numbers (`stat`, `bars`), diagrams (`flow`, `hub`, `versus`, `grid`), kinetic `title`/`punch`. Screenshots and og images only as supporting cards.
- **Text role:** a kinetic headline per beat (2–7 words) plus word-synced captions, *or* `captionStyle: "none"` when the headline carries every beat (Creator 30 style).
- **Theme:** night / paper / swiss / terminal per topic mood (art-direction.md).

## Beat template (spotlight, 40–50 s)
| t | beat | scene types |
|---|---|---|
| 0–3 s | hook: payoff + a visual that *literally* shows the sentence | `title` (box/em) or `repo` → `hub` |
| 3–8 s | name + credibility | `repo` (odometer), `stat` |
| 8–25 s | mechanism in 3–5 compositions | `terminal`, `flow`, `chat`, `code` |
| ~50% | re-hook "but here's the smart part" | `punch` → `versus` |
| | proof | `bars`, `quote` |
| | caveat / who it's not for | `title` with `_muted_` sub |
| last 3 s | CTA that shows the action | `cta` |

## Pacing and audio
1.5–3 s per scene, a pattern interrupt (`punch`/`stat`) every 8–12 s, 195–235 wpm, bed −25 dB with automatic whoosh/pop/type SFX.

## Workflow
Default pipeline. Image budget usually 0–2 (prefer rebuilt UI). 14–20 scenes.

## Pitfalls
- Three dense scenes in a row (repo → terminal → code) reads like a README: alternate dense and light.
- A headline that transcribes the VO. It must complement it.
