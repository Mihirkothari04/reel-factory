# Category `top-n`: a numbered list of repos / skills / plugins / tools

**Read only when** the reel presents several tools as a list ("5 Claude Code skills you need", "3 free tools to cut token use", "30 best plugins"). Evidence: 13 batch-04 reels (median 52 s, 43–60; 206 wpm) plus the earlier catalog reels (Creator 63 30 plugins, Creator 48 20 repos, Creator 62 45 places). The general `catalog` mode playbook still governs density; this file adds how dev-tool lists are built.

## Who watches and why the reel is built this way
The viewer wants a **curated shortlist to save** and all the links at once. The creator's value is the curation ("I deleted every skill except these 6"), so the reel shows the size of the list up front (an open loop with a visible end), gives each item one job and one proof, and ends on a frame worth screenshotting. The keyword CTA is natural here: one comment gets every link.

## Opening lock (verbatim corpus patterns)
- Number + promise: "Here are the five best Claude Code MCP servers you need to know."
- Reduction: "Claude has over 100,000 skills… but honestly, you only need five."
- Prohibition: "Do not build a new website until you have these six Claude skills."
- Elimination: "I deleted every Claude skill for design except these 6."
- Outcome first: "You will never hit your Claude usage limit after watching this." → "three free tools cut token usage by 70 %."
- Forbidden-fruit: "Five free repos that should be illegal."

## The visual COMMIT (show the list's size in the first 2–4 s)
| device | how | best when |
|---|---|---|
| flash preview | every item's hero screen for ~0.3 s under S1 (fast `shots`) | 3–6 visually distinct items |
| blurred slots | all N chips/tiles present but blurred; each unblurs when named and stays sharp; the stack returns between items as the hub | the names are the payoff |
| drawn countdown | numerals 1→N with arrows pop onto a pile of files as "you only need five" is said | reduction hooks |
| install log | the N installs typed into the agent as the preview | agent-skill lists |
| grid build | tiles fill one by one, grouped by job ("WEB / MOTION"), each with a one-word verb | micro-lists, silent lists |

## Item grammar (repeat identically for every item)
1. **Marker** (≤ 1 s): a punch-in on the presenter with "No. N" (in top-n reels our `close` layout may repeat once per item; the general limit of 2 does not apply here), or a numeral slam on the chest, or a persistent "#N NAME" pill.
2. **Name** typed or shown with its logo, and its job in one clause ("writes the design brief").
3. **One proof shot** of *what changes* (its output, its SKILL.md line, a micro-widget, its star count), 2–5 s.
4. Back to the hub (stack/face).

Order: escalating wow with the strongest second-to-last, or a **pipeline order** (brief → code → design → components → motion), or fame order (biggest stars first, the private/local one last). ~7–9 s per item for 5 items; 12 s each for 3.

## Close
- A recap frame: the N logos stacked with a dotted arrow, an icon row, or the grouped job grid. Hold ≥ 2 s; it is the screenshot.
- A one-line roll-up by job ("usage, video, output, data and security").
- An optional restraint line ("don't install all of them; the wrong ones clutter your terminal").
- The CTA: the keyword delivers all N links / install commands in one DM; the withheld bonus works ("…plus 3 more for sound").

## Construction with our studio engine
- `presenter` split/corner with `close` item markers; or `catalog` (`carousel` + `sheet`) for 10+ items; `silent` for micro-lists (≤ 10 s, loopable, a moving background under the grid).
- `meta.progress` chips for the ToC; `scene` shots `grid`/`list`/`sheet` for recap frames; gfx `label` + `icon` for each item's pill.

## CTA and caption
- Caption lists **every item** with `name → outcome` (the reel only flashes them); links stay behind the keyword. Line 1 = the keyword or the hook.

## Pitfalls seen in this category
- A visual from a *different* item while one is being named (the viewer maps every visual to the item).
- 10–15 s of face-only talk after the last item; several stacked CTAs.
- Reading each tool's description aloud instead of its job.
- No visible count for long lists; a hook number that doesn't match the items.

Evidence (batch-04): Creator 37 (5 skills: face-close markers, drawn countdown, Star History; 5 plugins; 5 free repos), Creator 85 (6 skills: blurred slots, pipeline order), Creator 90 (6 skills in 8 s: elimination hook, grouped job grid, "← rendered this video"), Creator 99 (3 token tools: flash preview, chest numerals, logo recap), Creator 73 (5 MCP servers: headroom pills, micro-widgets), Creator 45 (5 skills: install-log preview, icon-row end frame), Creator 77 (5 free repos: flash preview), Creator 63 (7 repos, 30 plugins: caption lists every item), Creator 78 (6 plugins: numeral bumpers), Creator 75 (5 video-editing skills), decodingai.vs (3 animation libraries).
